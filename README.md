# Vertex - Developer Toolkit

Vertex is an all-in-one developer toolkit designed to supercharge your workflow. It consolidates scattered development tools into a single, comprehensive, dynamic dashboard optimized for productivity and speed.

## Features

- **Project Scaffolder**: Generate best-practices folder structures and run one-click scaffolding bash commands for popular tech stacks like MERN, Next.js, Django, Vue 3, Spring Boot, and Flutter.
- **My Workspace**: Save, manage, and retrieve personal code snippets.
- **Git & GitHub Explorer**: Visualize repository structures and network history with a full 3D node map using Three.js! Review repository insights, stargazers, commit frequency, and inspect GitHub user profiles directly. 
- **Command Reference**: Never memorize terminal commands again. Easy-to-use search lists step-by-step workflows for Git, NPM, and general terminal utilities.
- **Tools Vault**: Curated lists of industry-leading dev tools, AI utilities, API clients, testing frameworks, and ready-to-use code boilerplates. 
- **Free APIs Base**: Huge catalog of free authentication-less and token-protected APIs (Weather, REST Countries, Stripe, Vercel, OpenAI, GitHub, etc) for your next project. 
- **AI Code Generator**: Describe the component you want, specify the framework, and let an AI model craft production-ready blocks that you can instantly copy!
- **Package Scout**: Deep dive into npm package analytics, including sizes, dependents, bundle optimizations, and github links.

## Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript, CSS (Variables, Grid, Flexbox)
- **3D Engine**: Three.js & OrbitControls (for Git Tree generation)
- **APIs Used**: GitHub API, Pollinations AI, NPM Registry

## Installation

No build steps required. Simply clone the repository and run `index.html`!

```bash
git clone https://github.com/adityajha-coder/Git-tool.git
cd Git-tool
npm start
# Or use live-server / python -m http.server to run locally
```
